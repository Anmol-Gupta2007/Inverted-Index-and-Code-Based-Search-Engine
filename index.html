Source Code Ingestion & Lexer (Anmol Gupta)

Traverses directories recursively, registers source files with unique monotonic Document IDs, strips single-line comments (//), multi-line blocks (/* */), and string literals to retain clean programming tokens.

Inverted Index Engine (Navneet Nainwal)

Implements an in-memory hash table using the djb2 hashing algorithm with separate chaining. Connects unique tokens to dynamically allocated singly linked postings storing {doc_id, tf, next}.

Implemented in C: index.c / index.h
M3

Boolean Query Engine (Harshit Kumar)

Processes multi-term queries and executes linear O(M+N) two-pointer list intersections (AND), unions (OR), and differences (NOT). Reclaims temporary memory via designated cleanups.

Implemented in C++: query_parser.cpp / query_parser.h

TF-IDF Ranker & Min-Heap (Atharva Goyal)

Calculates document relevance scores using Term Frequency (TF) and Inverse Document Frequency (IDF) with logarithmic scaling. Maintains a Min-Heap for Top-K extraction and formats CLI outputs.

Implemented in C++: ranker.cpp / minheap.h
